# Enzo Thome — Brand Book

## Core palette

The visual identity uses one navy blue, one warm white, and black only.

| Role | Color | Hex |
| --- | --- | --- |
| Primary blue | Navy | `#0F172A` |
| Primary white | Warm white | `#FAF9F6` |
| Black | Black | `#111111` |

## Usage guidance

- Use `#0F172A` as the only blue in future designs and interface work.
- Use `#FAF9F6` as the only white in future designs and interface work.
- Use `#111111` when black is needed.
- Any other existing colors are decorative only and are not part of the core brand palette.
- Do not change the current website unless a task explicitly asks for visual or styling changes.

## Brand backgrounds

- `public/brand/background-grain-navy.png`: dark, navy-dominant background for light content.
- `public/brand/background-grain-warm-white.png`: light, warm-white-dominant background for dark content.
- Both backgrounds use the core navy and warm white only, with fine grain and soft organic transitions.
